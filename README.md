# LHG Wheels

Dispatch logging for Hin Gen (part of the LHG apps). Rewards live in LHG Journey.

- Log in with your **phone number** and password (same account as LHG Journey).
- Who can open Wheels: Admin, HR, Operation, Logistics.
- Run locally: `npm install`, then `npm run dev`, open http://localhost:3000.
- Database changes live in `supabase/` — run each new migration once in Supabase → SQL Editor.
- See `PROJECT_STATE.md` for how everything fits together, and `SWITCH_TODAY.md` for the phone-login switch.
